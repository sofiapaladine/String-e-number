Lista de Exercícios — JavaScript Number API

10 exercícios práticos com dificuldade progressiva

1. Arredondamento de um número

Considere:

const valor = 17.684;

Crie um programa que exiba:

  1. O número arredondado para o inteiro mais próximo.
  2. O número arredondado para baixo.
  3. O número arredondado para cima.

Resultado esperado:

18
17
18
Conceitos: Math.round(), Math.floor(), Math.ceil().

2. Formatação de casas decimais

const preco = 149.98765;

Exiba o preço com exatamente duas casas decimais.

Resultado esperado:

149.99
Conceito principal: toFixed().
Desafio: transforme o resultado em um número novamente, em vez de deixá-lo como string.

3. Conversão de string para número

const valor1 = "25";
const valor2 = "17.5";

Converta os dois valores para números e calcule:

  1. A soma.
  2. A diferença.
  3. O produto.
  4. O quociente.

Resultado esperado:

Soma: 42.5
Diferença: 7.5
Produto: 437.5
Quociente: 1.428571...
Conceitos: Number(), operações aritméticas.

4. Verificação de número válido

Considere:

const valor = "123.45";

Crie um programa que verifique se o conteúdo pode ser convertido para um número válido.

O programa deverá informar:

Valor numérico válido

ou:

Valor inválido
Conceitos: Number(), Number.isNaN().

5. Verificação de inteiro

const numero = 42.0;

Verifique se o valor armazenado na variável é um número inteiro.

O programa deverá exibir:

O número é inteiro.

ou:

O número não é inteiro.
Conceito principal: Number.isInteger().
Desafio: teste também os valores 42.5, "42" e NaN.

6. Maior e menor número

Considere o conjunto:

const numeros = [17, 4, 89, 32, 12, 56];

Crie um programa que encontre:

  1. O maior número.
  2. O menor número.

Resultado esperado:

Maior: 89
Menor: 4
Conceito principal: Math.max() e Math.min().
Desafio: utilize o operador spread (...) para passar os elementos do array aos métodos.

7. Geração de número aleatório

Crie uma função chamada gerarNumero() que retorne um número inteiro aleatório entre 1 e 100, incluindo os dois extremos.

Exemplo de utilização:

console.log(gerarNumero());

O resultado deverá ser um inteiro entre 1 e 100.

Conceitos: Math.random(), Math.floor().

8. Cálculo de média

const nota1 = 7.5;
const nota2 = 8.25;
const nota3 = 9.0;

Calcule a média das três notas e exiba o resultado com duas casas decimais.

Resultado esperado:

Média: 8.25
Conceitos: operações com números, divisão e toFixed().
Desafio: crie uma função que receba qualquer quantidade de notas.

9. Limites numéricos

Crie um programa que exiba:

  1. O maior número inteiro seguro que o JavaScript consegue representar com segurança.
  2. O menor número inteiro seguro.
  3. O maior valor numérico finito.

Utilize propriedades da classe Number.

Conceitos: Number.MAX_SAFE_INTEGER, Number.MIN_SAFE_INTEGER, Number.MAX_VALUE.
Desafio: explique a diferença entre MAX_SAFE_INTEGER e MAX_VALUE.

10. Validação completa de valores numéricos

Crie uma função chamada analisarNumero() que receba um valor e informe:

  • Se o valor é realmente um número.
  • Se é um número inteiro.
  • Se é um número finito.
  • Se é um número seguro para operações inteiras.

Teste a função com:

analisarNumero(42);
analisarNumero(42.5);
analisarNumero("42");
analisarNumero(Infinity);
analisarNumero(NaN);
Conceitos: Number.isNaN(), Number.isInteger(), Number.isFinite(), Number.isSafeInteger().
Desafio: faça a função retornar um objeto contendo todas as informações da análise.
